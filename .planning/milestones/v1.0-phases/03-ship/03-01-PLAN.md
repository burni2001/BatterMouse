  <name>Task 1: Draw tray.ico using ImageMagick (16/32/48 px, white mouse+battery silhouette)</name>
  <files>BatterMouse/Resources/tray.ico</files>
  <action>
Generate a multi-size ICO file using ImageMagick (`magick` command). The icon must show a mouse silhouette with a small battery indicator, in white/light gray so it is visible on both dark and light Windows taskbars.

Design (Claude's discretion within these constraints):
- Background: transparent
- Color: white (#FFFFFF) or light gray (#E0E0E0)
- Shape: simplified mouse body (oval/rounded rectangle ~60% of canvas height) with a small rectangular battery symbol in the lower-right quadrant (3-4 px wide at 16px scale)
- At 16x16: the shape must be recognizable — keep it simple, 2-3 pixel stroke
- At 32x32 and 48x48: same design, proportionally scaled

Approach — generate each size as a PNG then combine into ICO:

```bash
# Step 1: Create 48x48 source art using ImageMagick drawing primitives
magick -size 48x48 xc:transparent \
  -fill white -stroke white -strokewidth 1 \
  -draw "roundrectangle 10,8 38,36 6,6" \
  -draw "rectangle 28,28 38,36" \
  -draw "rectangle 30,30 36,34" \
  -fill transparent -stroke black -strokewidth 0 \
  /tmp/bm48.png

# Step 2: Generate multi-size ICO from the 48px art
magick /tmp/bm48.png -define icon:auto-resize=48,32,16 \
  "BatterMouse/Resources/tray.ico"
```

Adapt the draw commands to produce a clean silhouette. If ImageMagick is not available via PATH, try `magick.exe` explicitly. The exact pixel layout is Claude's discretion — the requirement is a white/light-gray mouse+battery shape legible at 16x16.

If ImageMagick is unavailable entirely, create the ICO programmatically using a minimal C# script (dotnet-script or inline csx) that writes a valid 16x16 ICO with a simple white rectangle + battery shape. See https://www.i-programmer.info/programming/graphics-and-imaging/927-raw-image-formats.html for ICO binary format (40-byte BITMAPINFOHEADER + pixel data). This is a last resort — prefer ImageMagick.

Verify the output file is a valid ICO: `file BatterMouse/Resources/tray.ico` should report "MS Windows icon resource".

<task type="auto">
  <name>Task 1: Create GitHub Actions release workflow</name>
  <files>.github/workflows/release.yml</files>
  <action>
Create the directory .github/workflows/ if it does not exist, then create release.yml.

The workflow must:
- Trigger on push of tags matching "v*.*.*" ONLY (not on branch pushes)
- Run on windows-latest (NOT ubuntu-latest — win-x64 WinExe publish requires Windows SDK)
- Have `permissions: contents: write` (required by softprops/action-gh-release to create releases)
- Use actions/checkout@v4, actions/setup-dotnet@v4 (dotnet-version: '8.0.x')
- Run `dotnet restore BatterMouse/BatterMouse.csproj`
- Run `dotnet publish BatterMouse/BatterMouse.csproj -c Release --no-restore -o publish/`
- Use `softprops/action-gh-release@v2` with `files: publish/BatterMouse.exe`

Complete YAML (use exactly this structure):

```yaml
name: release

on:
  push:
    tags:
      - "v*.*.*"

permissions:
  contents: write

jobs:
  build-and-release:
    runs-on: windows-latest

    steps:
      - uses: actions/checkout@v4

      - name: Setup .NET 8
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'

      - name: Restore
        run: dotnet restore BatterMouse/BatterMouse.csproj

      - name: Publish
        run: dotnet publish BatterMouse/BatterMouse.csproj -c Release --no-restore -o publish/

      - name: Create GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          files: publish/BatterMouse.exe
```

Do NOT use ubuntu-latest (produces link errors for win-x64 WinExe).
Do NOT use actions/create-release (archived/deprecated).
Do NOT add --self-contained or -r flags to the publish command — these are already declared in BatterMouse.csproj (PublishSingleFile=true, SelfContained=true, RuntimeIdentifier=win-x64).
